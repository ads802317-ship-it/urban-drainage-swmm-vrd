#  Urban Drainage & VRD Network Design (EPA SWMM)
> **Hydrological modeling, network sizing, and sustainable stormwater management**

##  Project Overview
Engineering study focusing on the hydraulic sizing and optimization of an urban stormwater drainage network. The project integrates traditional drainage systems with sustainable green infrastructure (*Low Impact Development - LID* / Best Management Practices - BMP).

---

##  Key Objectives
* **Spatial Analysis & Watershed Delineation:** DEM processing and land use classification using **QGIS / ArcGIS**.
* **Hydrological Calculation:** Peak flow rate estimation for a 10-year return period ($T = 10 \text{ years}$) using Rational and Caquot methods.
* **Dynamic Modeling (EPA SWMM):** Network simulation, surcharge analysis, and integration of stormwater infiltration structures (swales, retention basins).
* **VRD & Civil Design:** Network layout and longitudinal profiles generated via **AutoCAD / Civil 3D**.

---

##  Repository Structure
* `/models/` : EPA SWMM simulation files (`.inp`).
* `/gis/` : QGIS/ArcGIS spatial analysis files and exported maps.
* `/dwg/` : AutoCAD network drawings and longitudinal profiles (`.dwg`, `.pdf`).
* `/calculations/` : Calculation sheets, hydraulic formulas, and design notes.
